open-compute {{ .Chart.AppVersion }} is installed as a single-node StatefulSet.

Access the API and Dashboard locally:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "open-compute.fullname" . }} 8787:{{ .Values.service.port }}

Inspect the instance and get a one-time Dashboard URL:
  kubectl --namespace {{ .Release.Namespace }} exec {{ include "open-compute.fullname" . }}-0 -c open-compute -- /opt/open-compute/ocd --no-update-check --system instances --json
  kubectl --namespace {{ .Release.Namespace }} exec {{ include "open-compute.fullname" . }}-0 -c open-compute -- /opt/open-compute/ocd --no-update-check --system dashboard --no-open
